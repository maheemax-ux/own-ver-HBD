# Jayadurga's Pixel Birthday Party

A static React birthday site. No backend, no accounts, no tracking. Wishes are saved in the browser's `localStorage`.

## Run locally

```bash
npm install
npm start
```

## Deploy on GitHub Pages

1. Push this repo to GitHub (branch `main`).
2. Go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. The included workflow builds and publishes the site on every push.
